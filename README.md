# Chresty

Windows desktop app based on [Frosty Toolsuite v1](https://github.com/CadeEvs/FrostyToolsuite), as a full UI rewrite.

# About

This is a unfinished project I started in Late 2023, as a continuation of the [Live Edit Plugin](https://github.com/shoushou1106/LiveEditPlugin_FrostyV1/). It still does not contains any real logic. I learned a lot about UI/UX while developing this project, it started with MAUI and later WinUI 3. Includes early imaginiation about the stucture of unified Frosty App. The name is a combination of "Frosty" and "Cheat Engine".
